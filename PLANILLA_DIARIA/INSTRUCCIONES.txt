PLANILLA DIARIA · 12 COLUMNAS

1. En Supabase > SQL Editor ejecuta supabase/ACTUALIZAR_TABLA_12_COLUMNAS.sql.
2. Copia los CINCO archivos index.html, app.js, importar_excel.js, styles.css y config.js dentro de la carpeta PLANILLA_DIARIA del repositorio, reemplazando los anteriores.
3. En la raíz del repositorio ejecuta:
   git add PLANILLA_DIARIA/
   git commit -m "Planilla diaria 12 columnas e importacion historica"
   git push origin main
4. En la web presiona Ctrl+F5 e inicia sesión.
5. Haz clic en Importar histórico Excel y selecciona el Excel que tenga la hoja PLANILLA DIARIA.
6. Luego usa Nueva actividad para ingresar manualmente.

Campos de la hoja: Fecha, No. orden de trabajo, Nombre área, Descripción equipo, Descripción actividad, Ejecutante, Hora, Tiempo real, Hora inicio, Hora fin, Total HH (min), Supervisor asignado.
Se mantienen los nombres de columnas ya usados por Supabase para no perder información.
El Excel se lee por encabezados y, cuando falta alguno, por las posiciones A,C,G,H,I,J,K,L,M,N,P,Q que mostraste.
No se sobreescriben registros históricos idénticos. Si una fila cambia, se considera otro registro.
El campo import_key debe tener índice único. La clave de acceso de usuarios NO se escribe en config.js.
Si aparece error por una columna adicional obligatoria de tu tabla, comparte el texto exacto del error para ajustar la compatibilidad.
