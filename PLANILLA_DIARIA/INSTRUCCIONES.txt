PLANILLA DIARIA - INSTALACIÓN
1. Ejecuta supabase/crear_tabla.sql en SQL Editor del proyecto existente.
2. Configura URL y clave pública en planilla-diaria/config.js. Nunca uses service_role.
3. En Supabase Authentication crea o invita usuarios autorizados.
4. Copia planilla-diaria/ a la raíz del repositorio, sin modificar ordenes/.
5. git add planilla-diaria/ && git commit -m "Agregar planilla diaria" && git push origin main
6. Abre /planilla-diaria/ e inicia sesión.
NOTA: El ZIP contiene la página funcional de captura y consulta, pero NO migra automáticamente el histórico. La migración inicial de programacion.json debe realizarse una vez, después de validar la fecha máxima y la correspondencia de campos. No cargar el histórico desde cada navegador.
